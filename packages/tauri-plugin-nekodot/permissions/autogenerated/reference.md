## Default Permission

Native client lifecycle, notification routing and user-initiated sharing

#### This default permission set includes the following:

- `allow-push-token`
- `allow-clear-push-token`
- `allow-focus-conversation`
- `allow-take-notification`
- `allow-share-file`
- `allow-background`
- `allow-register-listener`
- `allow-remove-listener`
