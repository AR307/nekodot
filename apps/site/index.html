装在你自己的电脑上

在 Windows 上添加电脑时选「这台电脑」，App 会自己把运行环境装好，不用另外租服务器。Bot 直接读写这台电脑上的文件。

你的电脑
聊天记录、Bot 设置、交付的文件和 API 密钥都存在这里
nekodot 服务
管账号、转发消息，聊天内容不存盘
App
只记住登录状态和语言这类偏好

模型请求会发给你选的模型服务商，所以 nekodot 不是离线运行，也没有端到端加密。想让 Bot 全天在线，可以改装在一台 Linux 服务器上。

要密码时，用加密框交给它

Bot 需要 API 密钥或密码时，会在聊天里弹出一个加密输入框。只给提出请求的那个 Bot 用，聊天记录里看不到原文。

还有：定时任务、交付文件的资料库、一个账号连多台电脑、节点自动更新、中英文和深浅色。

开源，
底下是 Hermes Agent

nekodot 以 MIT 协议开源。每个 Bot 就是一个原生的 Hermes Agent，记忆、技能和工具调用都由 Hermes 完成。nekodot 不改 Hermes，只做界面、连接和多个 Bot 之间的协作。

  • 模型用你自己的：账号授权登录，或者填自定义 API，每个 Bot 可以用不同的模型
  • Hermes 的原生设置都能在 App 里直接改，不用碰配置文件
  • 想自己部署整套服务也行，步骤写在 GitHub 上

三步开始

下载 Windows 版 下载 Android 版

0.3.2 正式版。Windows 10 / 11 x64，安装器还没有发布者签名；Android 10 以上 arm64，APK 已签名。macOS 和 Linux 桌面版暂时没有安装包。

  1. 下载 App，用邮箱注册

    收到验证码，填进去就行。

  2. 给 Bot 找一台电脑

    在 Windows 上直接选「这台电脑」，App 自动装好。想全天在线，就在 Linux 服务器上运行 App 给的一行命令。

  3. 添加模型，建第一个 Bot

    起个名字，写一句它负责什么，它会先跟你打个招呼。
