你的电脑只向外连接，
一个端口也不用开。

  1. App 只保存登录状态和偏好
  2. Relay 账号、配对和路由，不保存聊天
  3. Node 你的机器：聊天记录、Bot 配置、交付文件
  4. Hermes 每个 Bot 一个 profile：会话、记忆、技能
  • 完整密钥只在你的节点上，界面只显示后四位。
  • 不修改 Hermes，只通过官方 CLI 与 API 集成。
  • 模型请求会发往你选的服务商；nekodot 不是离线运行，也没有端到端加密。

下载 Windows 版 下载 Android 版

0.2.0 正式版。Windows 10 / 11 x64，安装器未做发布者签名。Android 10+ arm64，APK 已签名。Android 真机与后台通知仍待完整验收。

  1. 安装 App，用邮箱注册

    App 自带界面，通过 HTTPS 连接服务。

  2. 配对你的服务器

    复制 App 生成的一行命令，在 Linux x64 服务器或 WSL2 上运行。注册不会获得别人节点的权限。

  3. 添加模型，创建 Bot

    授权登录或填自定义 API，起个名字，写一句它负责什么。
