nekodot

替你把事做完的 AI 助手。

跟它说一句要做什么，它用你电脑上的文件和浏览器把事做完。你在电脑或手机上派活、看进度、点头放行。

下载 Windows 版 下载 Android 版

一个 Bot，一句话，
一件事办完

跟它说一句要做什么，它自己查网页、读文件、跑命令，做完把结果和文件交给你。干活时它会说一句正在做什么，每一步都收在对话里。

  • 要跑命令、改文件，先停下来问你：允许一次、这次都允许、以后都允许，或者拒绝
  • 干到一半想补一句，直接发；方向不对就按停止
  • 拿不准的地方，它会停下来问你

你的模型，你的电脑，
你的隐私

模型用你自己的：账号授权登录，或者填自定义 API，每个 Bot 可以用不同的模型。Bot 装在你自己的电脑上，在 Windows 上添加电脑时选「这台电脑」，App 会自己装好运行环境，直接读写这台电脑上的文件。

你的电脑
聊天记录、Bot 设置、交付的文件和 API 密钥都存在这里
nekodot 服务
管账号、转发消息，聊天内容不存盘
App
只记住登录状态和语言这类偏好

模型请求会发给你选的模型服务商，所以 nekodot 不是离线运行，也没有端到端加密。

打开它的屏幕，亲手接一下

跑腿在网页上碰到验证码会叫你。打开它的屏幕点「接管」，填完再交还给它。

屏幕用于 Linux 服务器上的 Bot。在 Windows 上，可以单独允许某个 Bot 操作这台电脑，默认关闭。

它记住的，你能直接改

它对你的了解、它自己攒下的经验，都是能打开编辑的文字。对你的了解会同步给你所有电脑上的 Bot。

  • arxiv按关键词搜论文 已安装
  • google-workspace读写表格、文档和日历 安装 已装给小研
  • pdf拆分、合并、提取 PDF 安装

装个技能，多一样本事

从 Hermes 的技能和插件目录里挑，先看说明再装。装给哪个 Bot，由你定。

OpenAI 笔笔要用它给周报画图表 API Key •••••••••••••••• 保存供笔笔以后用 加密交付 已交付，只给笔笔用

要密码时，用加密框交给它

Bot 需要 API 密钥或密码时，会在聊天里弹出一个加密输入框。只给提出请求的那个 Bot 用，聊天记录里看不到原文。

还有：定时任务、交付文件的资料库、一个账号连多台电脑、节点自动更新、中英文和深浅色。

开源，
底下是 Hermes Agent

nekodot 以 MIT 协议开源。每个 Bot 就是一个原生的 Hermes Agent，记忆、技能和工具调用都由 Hermes 完成。nekodot 不改 Hermes，只做界面、连接和多个 Bot 之间的协作。

  • Hermes 的原生设置都能在 App 里直接改，不用碰配置文件
  • 想自己部署整套服务也行，步骤写在 GitHub 上
