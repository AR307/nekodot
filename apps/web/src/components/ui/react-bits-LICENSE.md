# ReactBits Gooey Nav attribution

Source: [DavidHDev/react-bits GooeyNav](https://github.com/DavidHDev/react-bits/tree/c83b5e7e026f003af33ff9ebc3d93afb5c86ad22/src/ts-default/Components/GooeyNav).

The DOM/CSS version is adapted for controlled application navigation, icons, theme tokens, compact particle distances, responsive sizing, keyboard access, reduced motion, and animation cleanup. Its blur/contrast compositing uses a local SVG alpha filter so it works on both light and dark surfaces without an opaque backdrop. No additional runtime dependency is required.
