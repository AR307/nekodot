# 四 Bot 真实接力：大模型论文构思

日期：2026-11-03。所有成员使用 gpt-6.1-sol；真实 Windows 原生候选、隔离 Node/Relay、Hermes v0.22.5。以下是群聊中论文统筹的最终输出，不是主助手代写。尚未执行论文实验，不能据此声称提升或已证实创新。

**题目：面向证据缺失与检索噪声的预算感知 RAG 拒答路由**

**摘要。**本研究计划在冻结的开源 7B 级模型与固定检索器上，研究 answer、retrieve-more、abstain 三动作决策：已有证据能否支持回答，追加检索是否值得，以及何时应在预算内停止。利用 HotpotQA 构造可恢复的首轮证据缺失、全检索池标注证据移除及干扰条件，比较不同实际成本下的答案质量、风险与覆盖率。当前没有实验结果；潜在贡献是对“追加检索收益估计”的成本匹配检验及可复现评测协议，**三动作组合本身不足以证明创新**。本轮未重新查阅原文，方法细节、模型资源需求及更广泛研究空白仍待核实。

**研究假设与边界。**H1：在相同覆盖率和相近实际成本下，利用当前证据与追加检索收益的路由，比单一充分性阈值具有更低风险。H2：相较“证据不足就追加”，收益估计能减少无效检索。H3：收益在证据缺失及困难干扰条件下仍然存在。这些均为待验假设，不附带理论风险保证。拒答只表示当前证据和预算不足；模型凭记忆答对而引用无支撑时，答案正确与证据有效应分别计量。

**最小算法。**固定一个开源 7B 指令模型、BM25 和语料快照，锁定版本、提示与生成参数。首次取固定数量段落，模型生成候选答案、段落引用和充分性评分。路由特征限于推理时可见信息：检索分数及其差值、候选引用覆盖、模型充分性评分、剩余预算；模型自评分不当作可信概率。

在拟合集上采集“立即回答”和“追加一批后回答”的配对轨迹，用轻量逻辑回归分别预测两阶段答案正确且有支撑的概率，以两者差作为追加检索收益估计。此差值只是预测量，并非已识别的因果收益。支撑标签采用 supporting facts 匹配代理并人工抽查，不能等同语义蕴含。

当前成功概率超过阈值则回答；否则，预算允许且预测收益超过成本门槛时追加检索，其余拒答。MVP 最多追加一次，使用同一 BM25 排序的后续段落，去重并限制上下文长度，不引入查询改写。追加后只允许回答或拒答。校准集选择阈值与成本门槛，测试前冻结；所有方法共用最终答案模板。

**数据与扰动。**从 HotpotQA 训练部分按问题 ID 划分拟合、校准和锁定测试集，同题所有扰动版本归入同一区；保存划分清单并审计跨区近重复。共享百科文档不自动构成泄漏，但测试答案、标注事实和扰动类别不得进入路由特征或调参流程。

采用固定语料池，包含样本相关段落与固定干扰池，明确这是受控评测，不能直接外推完整维基检索。设置原始条件、首轮移除但后续可恢复、整个可检索池移除标注证据，以及长度匹配的主题相近干扰；后者避免依靠明显矛盾文本制造识别捷径。标注事实移除不等于不可回答，需抽查替代证据、残留答案线索与误删。扰动脚本可用标注定位证据，路由运行时不可读取这些标注。

**基线、预算与指标。**基线包括单次 RAG、单次 RAG 加拒答、固定追加检索加拒答、充分性不足则追加，以及复杂度代理路由加拒答。复杂度代理明确标作工程基线，不声称复现 Adaptive-RAG。各方法统一模型、检索器、上下文上限和生成设置；候选生成、评分、重试均计入成本。既设相同资源上限，也比较多档实测成本前沿；相同调用次数不能替代成本匹配。

报告全体与已回答子集的 EM/F1，全体指标中拒答计零；risk–coverage 分别采用答案错误率和“答案错误或无支撑”率。引用支撑率以已回答样本为分母，另报引用段落的标注事实命中率与人工支撑判断，避免混用。记录输入输出 token、检索次数、实测延迟及峰值显存。置信区间按问题 ID 聚类配对抽样，避免将扰动版本视为独立样本；比较相同覆盖率下的风险，防止更多拒答造成表面改善。

**一至两周 MVP 与验收。**以单张可容纳所选模型的 GPU 为资源目标；量化方式、显存与吞吐须先实测，不预报 GPU 小时。第一周完成小样本吞吐测试、数据隔离、扰动抽查及配对轨迹；第二周拟合路由、校准、冻结并运行测试。样本规模根据预试吞吐在最终测试前确定，记录实际 GPU 小时；资源不足时缩小拟合集与实验矩阵，保留核心基线和锁定测试。

消融移除收益估计、预算特征、充分性评分，并与相同特征的直接动作分类器比较。若成本匹配后不优于最强简单基线、优势只来自降低覆盖率，或引用提升仅存在于自动代理而未获人工支持，应判定核心假设未获支持。主要不确定性包括检索排序后续批次收益有限、标注支撑不完备、参数记忆、受控扰动与真实噪声存在差距，以及单模型结论外推有限。

**与真实文献的关系。**Self-RAG 已涉及检索控制与支撑评价；Adaptive-RAG 已研究自适应检索策略；CRAG 已评价检索质量并触发纠正。因此本题暂定位为待验证的实证贡献，仍须补查选择性问答、可回答性与预算约束检索文献后判断新颖性。
