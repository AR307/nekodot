# 来源分组错误下定向核验的失效边界：固定预算工具问答的实证研究方案

状态：研究构思与合成原型已完成；真实 LLM 效果、新颖性与部署风险控制未验证。

## 摘要

本项目研究一个可在 1–2 周内以冻结模型、公开证据快照和小额 API 预算检验的问题：当来源字段缺失、错误拆分或错误合并时，按“未见来源”选择一次补充证据，何时比普通按排名补取更差？已有工作覆盖静默工具错误、来源依赖和重复报告计权。[5][6][7] 纠正检索及复制依赖推断也有直接先例，本项目不将这些机制重新包装为创新。[8][9] 本轮已运行纯 Python 标准库合成回放，另由统筹独立复跑并核对完整 CSV、三个数据/预测文件哈希和八项检查。观察到缺失与误拆条件下定向补取劣于分组加普通补取，且门控策略校准后全部拒答。因此研究重点是量化失效边界，候选贡献是可复现的评估证据，而非预先承诺一种有效新算法。

## 研究问题与待验假设

主问题：给定相同候选池、上下文上限和实际成本约束，来源分组加定向补取相对来源分组加普通补取的收益，如何随来源缺失、误拆、误并而改变？固定预算下的失效边界是否在真实公开证据上出现？

- H1（待验）：分组误差较小时，定向补取降低固定覆盖率下的错误采纳。
- H2（待验）：缺失、误拆及误并有不同影响，不能用单一“噪声率”概括。
- H3（探索性，待验）：冲突触发可减少成本而维持部署覆盖率；当前原型对该目标的观察是失败。
- 不主张：新颖性已证实、不同域名意味着独立、真实分组必然提高准确率、模型分数已经校准。

## 已实现的最小算法与边界

输入：8条初始证据，各含URL、文本、支持方向和observed_origin；5条候选的元数据。选择时不读取候选正文或方向。输出：支持、反对或拒答，原始聚合分数、候选索引和补取次数。

```text
输入 initial, candidate_metadata, fetch, frozen_threshold
对初始证据：
    key = observed_origin（若存在），否则为规范化全文
    各组平均支持方向；score = 所有组均值的平均
若策略要求补取，且未超过预算：
    普通策略选择排名第一的候选
    定向策略选择首个来源字段已知且尚未出现的候选
    找不到则回退排名第一
    调用 fetch，加入一条证据，重新聚合
score = 0 或 abs(score) < frozen_threshold 时拒答
否则输出 sign(score)
```

可证明的有限性质：组划分和组数固定、某组内所有方向一致时，添加该组的同方向副本不改变分数。组内存在冲突时不成立；八项执行检查不等于一般形式证明。正式生产接口只接收候选元数据并通过单独fetch揭示正文，避免依赖“不读已传入的答案”的约定。

当前 clean 的 observed_origin 直接等于隐藏真实根，其余条件是随机损坏该字段；这是“给定含错分区”的机制回放，没有实现来源发现。后续可实施分组仅采纳公开可观察的显式转载/引用链、规范URL及开发集冻结的文本规则；未知关系保持未知。同域名、同结论或文本相似均不能单独证明共同来源；不同根也不证明统计独立。

## 本轮实际执行与观察

原型仅用标准库，无安装、训练、GPU、模型API或真实检索效果实验。固定种子271828；600题，开发200、测试400；来源方向正确概率0.72、各类损坏概率0.6均为生成器假设，不是观测到的网络分布。五条候选元数据免费可见也是合成假设。

统筹使用附件源码独立运行，退出码0，八项检查通过；完整CSV与附件逐字一致，三个数据/预测文件SHA256均匹配。进一步实际执行 lead_verify.py，确认下表及接受集合差异。

| 合成条件 | 普通补取错误数 | 分组＋普通补取错误数 | 分组＋定向补取错误数 | 后两者共同回答题数 |
| -------- | -------------: | -------------------: | -------------------: | -----------------: |
| 完整     |             64 |                   45 |                   41 |                302 |
| 缺失     |             64 |                   57 |                   59 |                309 |
| 误拆     |             64 |                   59 |                   60 |                317 |
| 误并     |             64 |                   61 |                   53 |                299 |

每种策略均按各自分数回答320/400题。这是离线80%覆盖率诊断，接受集合不同，不能解释成同一批320题的逐题纠错。尚无显著性结论。

必须保留的失败：缺失、误拆时定向组合更差；误并时只分组71错、多数票65错；门控平均补取0.5275次，但四条件最终接受量都为0，选择性错误率为null（未定义）。URL全部唯一，URL基线退化；模板文本基线有69次强制平局；当前“补取”只是揭示候选，未测真实搜索、等token、等美元效果。原oracle补取0次、组合补取1次，故不能称其为上界。

## 正式实验设计（尚未执行）

### 数据与泄漏隔离

限于公开、静态、非医疗法律金融决策的可核对事实声明；不把需要动态时效推断的问题混入首轮。每题固定公开原始记录、检索快照、抓取时间、文档哈希、转载/引用关系及人工真值。先检索并核对数据集许可和证据可访问性；若没有适合的小数据集，整理并公开小型材料集，明确采样偏差。现有数据集可用性未完成验收。

建议开发150题、独立校准200题、最终测试400题；这是上限设计，实际费用与标注资源不满足则在查看测试标签前统一缩减并重新预注册，不能声称原定功效。按底层事实、事件和转载连通分量分组后划分，不只隔离URL。人工来源根和真值放评估端；难以认证的关系标unknown，不强填“独立”。最终测试标签不能用于分组规则、提示、阈值或策略选择。

实验分两层：A层对人工分区分别施加0%、20%、40%、60%的缺失/误拆/误并，用于受控机制曲线；B层只使用自然可观察元数据和冻结分组规则，用于可部署效果。A层给定分区结果不能代替B层来源发现验证。自然噪声与人工干预分别报告。

### 基线、消融和模型

冻结一个廉价API模型的精确版本、提示、解码参数与输出格式；若公开模型资源已就绪，可用单张GPU替代，禁止长训练。不假定API现有授权或报价。模型负责证据方向抽取并保存原始回答；共享抽取用于隔离检索策略，另报告实际端到端成本，不能把共享部分说成免费。

必做对比：直接采纳/多数票；规范URL去重；开发集调好的文本去重；短声明＋引用提示；普通补搜；只分组；分组＋普通补搜；分组＋定向补搜。冲突门控为次要探索性消融。两种补搜使用相同聚合器和分组规则。补充真分组＋普通/定向补取参照并匹配预算，名称为“真分组参照”，不称严格上界。简化纠正检索基线需明确实现差异，不冒称完整复现CRAG。

### 成本公平性

所有方法面对同一冻结的初始检索结果和候选发现接口。主实验每题最多一次额外搜索、一次额外正文获取；普通策略与定向策略拥有相同候选元数据。定向查询生成若用LLM，也计入预算。候选发现、初始检索、抓取、抽取、提示与输出token、失败重试、缓存和延迟均进入账本。

正式运行前根据实际模型tokenizer锁定总上下文上限与每证据截断规则。每策略执行相同调用/输入输出上限，另在匹配美元预算曲线上比较；不将“上限相同”表述为实际消耗完全相等。昂贵策略不能隐去候选发现费用；纯回放与真实重新检索应分别呈现。

预算硬上限50美元，属于项目约束而非供应商报价。先核实官方价格并用公开材料小样估费；设检索/复查预算和模型预算，所有付费调用在真实授权与计费能力可用后进行。若本环境只能取得工具调用次数而无法核实实际美元费用，只能报告调用/token预算结果，不能宣称通过等美元验收。

### 校准、统计与预先锁定的标准

主对比：分组＋定向补取减去分组＋普通补取的选择性错误率差；主条件为B层自然元数据。主图是离线风险—覆盖率曲线，80%覆盖率为预定主截面；该截面按各自分数排序，标签不参与排序，但不是部署阈值。

部署阈值和超参只在开发集确定；独立校准集仅评估冻结阈值，不按其结果反复调参。预定最低测试覆盖率80%、选择性错误率目标10%；报告二项区间，但本方案不声称有限样本风险保证。若独立校准不达目标，记录失败或返回开发阶段并使用新的校准数据，不能继续复用旧校准集选阈值。全拒答错误率记NA，直接不满足覆盖率要求。

按完整问题ID配对bootstrap并在每次重采样重新计算各方法的选择和风险；按事实/转载簇重采样处理相关性，固定随机种子。报告95%区间、共同回答集合错误、拒答迁移、干净证据准确率、来源覆盖、误拆/误并率、抽取错误与成本。固定覆盖率的主效应是策略整体差异，不能只在共同集合里选择性报告胜例。次要噪声曲线及多条件比较标探索性，或预先指定多重检验校正。

预先将2个百分点的选择性错误率降低视为具有实际意义的候选效果：若主差异点估计达到该幅度且95%区间上端低于0、部署覆盖率不低于80%、预算达标，才支持主假设。若仅点估计改善但区间跨0，记证据不足；本设计尚无pilot功效估计，不保证400题足以检测该幅度。若收益方向相反，或违反预算/覆盖率，则不支持主假设。干净证据准确率比同预算普通策略下降超过2个百分点，或自然噪声效果仅存在于真分组参照，均判该策略不适于当前设定。

## 失败判据与止损

- 普通补搜、简单去重或短提示已解释收益：不能主张组合机制提供额外价值。
- 只有真分组参照有效：不得称实际来源发现有效。
- 收益来自额外拒答、候选信息、token或费用：成本/覆盖率公平性验收失败。
- 门控没有满足覆盖率与风险目标的阈值：记校准失败，不报零风险。
- 误并抑制独立来源，或跨自然噪声与种子不稳定：报告失效区间；不得删除负面条件。
- 区间跨零：证据不足，不等于证明无效。文献覆盖本研究问题：调整为复现/审计项目，不制造创新声明。
