## 审查发现与必要修正

1. 标签边界：当前策略路径未发现答案标签被直接用于选择；全部候选 vote/text 扰动检查通过。但 clean 条件的 observed origin 与 hidden root 完全一致，其他条件是对真值分组的随机损坏。应命名为“给定含错分区的机制实验”，不称真实来源发现。开发/测试来源 ID 隔离只是生成器结构，不证明真实事实、转载链或时间泄漏已消除。生产接口应只传候选元数据，而非完整候选对象后约定不读取。

2. 校准：阈值按每条件开发集经验错误率挑选，无有限样本风险保证。四条件 group_gated 测试接受量均为零，selective_error 为 null；不能报零错误率成功。正式设计应将策略/超参开发与最终阈值校准分开，锁定后一次评估测试；如主张风险控制，预先规定置信上界、选择校正和最低覆盖率。测试80%覆盖率按测试分数排序，未读答案标签，但属于离线风险覆盖诊断，不能当部署阈值。

3. 基线：初始 URL 全部唯一，URL去重在此退化；模板文本的相似度可把 YES/NO 合并，文本基线有69次强制平局。需增加真实重复URL、近似转载和独立同结论文本；仅在开发集调文本阈值，并加入短声明+引用提示与同预算普通检索。

4. oracle 命名：当前 oracle 平均补取0次，group_novelty补取1次，故不是组合方法的上界；即使补齐预算，真实分组在有限样本固定聚合器下也不保证点点支配。应提供匹配普通/定向补取的真分组诊断，标为参照而非严格性能上界。

5. 成本：五条候选元数据免费可见，未计候选发现、搜索、抓取、抽取、重试、token与延迟。一次补取只对应一次候选揭示，不是已执行一次真实搜索。等证据条数不等于等token/美元。需保存费用账本和冻结快照，报告共享抽取摊销与端到端费用，50美元目前只是硬预算设计。

6. 固定覆盖率：group_ordinary与group_novelty各回答320题，但clean/missing/split/merge共同回答数分别为302/309/317/299。此比较可用于整体选择性风险，不能解读为同一320题逐题纠错。应按完整问题ID配对重采样并重新计算各自风险覆盖指标，补报共同回答题的错误、拒答迁移和覆盖率，不能只bootstrap各自接受样本。

## 已观察的失败与下一步验收

缺失条件定向组合59错、普通组合57错；误拆60对59。只分组在误并条件71错，多数票65错。四条件门控校准均全拒答。以上是单种子合成现象，没有显著性或真实模型收益结论。

正式方案应预先锁定主对比、最低覆盖率、误并可接受损害、成本上限及失败阈值。若定向核验在同预算与同覆盖率下不能优于普通补搜、收益由额外拒答或真值分组解释，或误并损害超过预定容忍，应判主假设失败。差异区间跨零应记“证据不足”，不等同证明无效。
