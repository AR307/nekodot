# Bot 历史会话与 GUI 切换

日期：2026-11-02。本次为 Side Phase 5 结项后的独立功能增强，不改动其已确认的验收边界。

## 使用方式

- 私聊右上角新增「历史会话与切换」入口；Bot 详情中也可进入「历史会话」。
- 按会话名称或 ID 搜索，显示当前会话、原生消息数和运行状态。
- 点击会话预览实际 Hermes 历史；预览不会改变当前聊天使用的会话，也不会调用模型。
- 点击「新建」可填写可选名称，或直接创建；点击列表「切换」后返回聊天，后续消息使用所选原生上下文。
- 历史预览保留「继续此会话」入口。新建和切换不删除旧记录，不重建 Bot profile，不清空其原生记忆和技能。
- Bot 自身读取旧会话继续使用 Hermes 原生 `session_search`，不维护第二套检索器，也不自动把全部历史塞进提示词。

## 实现范围

Flutter 复用既有 `sessions.list`、`sessions.history` 和 `commands.execute` / Operations，最终调用既有 canonical `session.list/history/create/resume`；没有增加服务端协议或执行引擎，也没有修改 Hermes 核心。

列表沿用 Hermes 的 live/stored 两类查询与原生数量限制（每类最多 200），按所属 Bot 的 profile 读取。当前任务运行时，新建/切换沿用服务端已有拒绝逻辑，不暗中停止任务。普通群聊顶栏不提供修改成员私聊上下文的入口。

**展示边界：** 主聊天时间线仍保留 nekodot 的持久交互日志，不因切换而改写或清空；某一原生会话的具体文本上下文在历史预览中查看。切换影响后续实际模型上下文，不宣称已把原聊天日志拆成多份会话时间线。
