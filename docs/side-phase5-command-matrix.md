工程快照 `4e503403bf`，Hermes v0.22.5。真实旅程按模块在持续迭代候选上完成，并非全部在最终 release 包重跑。目录分类不是验收通过数。Android 是固定复用模拟器，不是真机。

余额恢复后，双端学习、原生目标/循环及 MoA/蓝图/cron 实际旅程重新完成。原生 heartbeat 的 local-session 缺陷与缺配置的语音功能单独标明。

动态 Skill 行只证明在真实 App 中完成原生加载及真实模型应答，不冒充 GitHub、邮箱、第三方 API、屏幕或文件制作的完整工作流。
