# 官网开场自动播放

2026-11-05，本地候选 `http://127.0.0.1:4390/`。

## 行为与实现

- 图片、当前语言与字体准备好后，截图弹出、8 个 Bot 依次跳出、名称卡片上浮并铺满，连续自动完成，约 5.2 秒。
- `main.js` 用可见时间驱动原有 `--p`；前 2.4 秒衔接截图与 Bot，接下来 2.8 秒推进卡片。CSS 入场动画与该时钟同步起播。
- 去掉三屏高度与 sticky 开场，不自动滚动、不拦截滚动；结束后保持 `--p: 1`。向下浏览、返回顶部、改变窗口尺寸均不倒播。
- 卡片未出现时，其下载链接不进入键盘焦点顺序；完整上浮后恢复。语言切换重新计算 Bot 与名称卡片的布局。
- 减少动态效果时沿用静态截图与卡片；标签页隐藏时暂停开场的 CSS 与 JS，返回后继续。
- 样式与脚本版本地址改为 `0.3.1-20261105-autoplay`，修复旧浏览器会话复用旧动画资源的问题。截图版本保持原值。

## 验收

- 改动前在 Edge 中不滚动等待 5.7 秒，名称卡片仍不可见（opacity 0），验收断言失败；改动后同一检查通过。
- 真实本地静态页面、真实 Edge、真实时间播放；无合成时钟、无滚动输入。1440×900 中文浅色、390×844 中文深色、768×900 英文浅色均自动完成，进度为 1、滚动位置为 0，首屏紧接下一节，无横向溢出、无脚本错误。
- 390×844 减少动态效果下直接显示静态内容；下载链接可用。额外用 agent-browser 检查 320×568 窄屏、开场中间帧、最终画面与导航进入群聊介绍；向下浏览再回顶部，进度保持为 1。
- agent-browser 的既有浏览器会话先复现旧资源仍播放滚动版，更新版本地址后，同一会话加载新脚本，零滚动播到终态。
- 隐藏/恢复的事件路径用浏览器内模拟 visibilitychange 检查：暂停期间 CSS 与进度均停止，恢复后完成。无头 Edge 的标签页切换始终报告 visible，未据此声称真实后台标签页验收通过。
- 相关 ESLint、Prettier 与 JavaScript 语法检查通过。原始检查脚本、JSON、分段截图与录屏在忽略的 `.runtime/site-autoplay/`。

本轮范围为静态官网，不涉及 Node、Relay、Hermes 或模型调用。手机为浏览器视口验收，未验手机真机、Safari/Firefox。仅本地提交，未部署正式网站。
