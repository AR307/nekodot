# Gooey Nav 实施计划

**Goal:** Web 与 Tauri 的全部分组导航使用 ReactBits Gooey Nav。

**Architecture:** `components/ui/gooey-nav.tsx` 集中控制选中胶囊的位置和 ReactBits 粒子效果，独立 CSS 使用现有 tokens。页面直接传递字符串值、显示文案、可选图标和 onChange，不另建路由。

**Tech Stack:** React 19、TypeScript、CSS、项目现有 useMediaQuery 媒体查询订阅。

## 约束

- 用户确认仅 Web + Tauri；Flutter 和静态官网不在范围内。
- 保留工作区已有改动及其暂存状态；仅本模块单独本地提交。
- 不增加依赖、运行时兼容层或凭证；不删除文件。
