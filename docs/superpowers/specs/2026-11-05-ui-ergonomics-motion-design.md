# 全功能人体工学验收与动效/排版系统（Web / Tauri）

用户要求：用人体工学手段验证所有功能，为所有功能界面设计动效与排版，达到企业级工程化验收。2026-11-05 用户确认范围与取舍，并授权自动执行全部步骤。

## 已确认的范围与取舍

- 范围：共用 React 的 Web / Tauri 界面（`apps/web`）。Flutter 原生与静态官网不改。
- 视觉：在 `design/08-motion.png`、`design/09-tokens.png` 及原 HTML 参考内系统化，不另起视觉语言；设计板未覆盖的场景按同一风格补齐。
- 真实验收：使用本次候选 Web、真实本地 Relay `4319`、Node、官方 Hermes 与用户自行配置的真实模型。提供方 Key 由用户在界面中填写，Claude 不代填；若验收时仍无模型来源，依赖模型的旅程记为未验，不以回放替代。
- 新增仅测试用开发依赖 `@axe-core/playwright`，不进入产品包。

## 现状（基线前已知）

- 动效时长硬编码：CSS 中 `160ms` 出现 57 次，另有约 20 种时长和 4 条 `cubic-bezier`；`motion/react` 调用处各写数值。只有 `--ease` 一个 token。
- 断点 7 种（480/520/767/1023/1279/1280 等）无统一刻度。
- 无焦点约束：`Sheet` 与 Bot 详情、命令面板、扩展（3 处）、文件预览共 6 个自写弹窗都不约束、不归还焦点，背景不 inert。
- 20–43px 的尺寸声明约 100 处，需逐项判定是否为可点击目标。

## 一、人体工学验证方法

可测量准则（每条在探针中有自动检查，或在真实走查中留证）：

| #   | 准则         | 阈值 / 判定                                                                                        |
| --- | ------------ | -------------------------------------------------------------------------------------------------- |
| E1  | 点击目标     | 可交互元素 ≥ 44×44 CSS px；正文内联链接除外；复选框/单选以其 label 计                              |
| E2  | 拇指可达     | 390px 下核心旅程的主操作（发送、弹层主按钮、新建）位于视口下半部或固定底栏                         |
| E3  | 可读性       | 正文 ≥ 14px，次要 ≥ 12px；axe `color-contrast` 无违规（文字 4.5:1，组件 3:1）                      |
| E4  | 键盘与焦点   | 全部操作可 Tab 到达且焦点可见；弹层内焦点循环、Esc 关闭、关闭后回到触发元素；背景 inert            |
| E5  | 反馈延迟     | 按下 ≤ 100ms 出现可见状态变化；等待 > 400ms 出现加载/进度表达                                      |
| E6  | 动效舒适     | 时长只取 token；退场用低一档时长；只动 transform/opacity；CLS < 0.1；交互期间无 > 200ms 的长动画帧 |
| E7  | 减少动态效果 | 无无限循环动画；所有 transition/animation ≤ 80ms 且无位移                                          |
| E8  | 重排与溢出   | 320/390/768/1024/1440px 无横向溢出；文本不被裁切；200% 缩放可用                                    |
| E9  | 语言与主题   | 中/英文案不截断，明/暗主题均满足 E3                                                                |
| E10 | 防错与恢复   | 危险操作有确认或撤销；表单就地校验；离线禁用并说明；失败可重试                                     |
| E11 | 触屏替代     | `hover: none` 下不依赖悬停才出现的操作                                                             |

工具：`tests/support/ergonomics.ts` 提供探针（axe、目标尺寸、字号、溢出、动画时长、减少动效、CLS、长动画帧、弹层焦点契约）；`tests/browser/ergonomics.spec.ts` 用录制环境逐面执行，作为可重复门禁；`tests/browser/ergonomics-live.spec.ts` 仅在提供本地 `NEKODOT_LIVE_ACCEPTANCE_FILE` 时连接真实环境运行，作为真实验收。

产出：`docs/ui-ergonomics/findings.md` 发现登记表（编号、界面、准则、P0–P3、证据、状态）。P0 阻断使用，P1 违反准则且影响主要旅程，P2 局部违反，P3 打磨建议。

## 二、动效与排版系统

### 动效 token（CSS 唯一来源 `styles/tokens.css`，TS 镜像 `src/motion.ts`，Vitest 校验一致）

| token           | 值                               | 用途（设计板对应）                  |
| --------------- | -------------------------------- | ----------------------------------- |
| `--dur-instant` | 80ms                             | 按下/颜色反馈；减少动效下的淡入淡出 |
| `--dur-fast`    | 160ms                            | 悬停、眨眼、小状态、`base` 的退场   |
| `--dur-base`    | 220ms                            | 消息出现、列表项、弹层退场          |
| `--dur-panel`   | 280ms                            | 屏幕面板、弹层/底部弹层、视图切换   |
| `--dur-slow`    | 450ms                            | 思考中点跳、大块展开                |
| `--dur-breathe` | 1200ms                           | 接管中描边呼吸                      |
| `--dur-pulse`   | 1400ms                           | 在线状态点外圈                      |
| `--dur-scan`    | 1600ms                           | 工作中头像眼睛扫视                  |
| `--ease`        | cubic-bezier(0.2, 0.8, 0.2, 1)   | 全部入场与移动（设计板唯一缓动）    |
| `--ease-pop`    | cubic-bezier(0.34, 1.4, 0.64, 1) | 配对成功等带回弹的确认              |
| `--shift-1/2/3` | 4 / 8 / 12px                     | 头像上跳 / 消息上浮 / 接力标签滑入  |
| `--stagger`     | 30ms                             | 列表错开，最多 6 项                 |

`motion/react` 弹簧：`spring = { stiffness: 400, damping: 32 }`（工具卡完成/展开）。

规则：只动 transform 与 opacity（布局变化用 FLIP/`layout`）；退场用低一档时长；一次性动画只播一次；循环动画仅限设计板所列状态；减少动效时关闭循环、去掉位移，统一 `--dur-instant` 淡入淡出。

设计板 12 项落位：消息出现、流式光标（1s steps，不逐字动画）、思考中（4px，450ms，错开 120ms）、工作中头像、空闲眨眼（4–7s 随机，160ms）、在线状态点、工具卡完成/展开（spring 400/32，spinner→✓ 150ms→取 `--dur-fast`）、Bot 接力（标签 12px 200ms→`--dur-base`，头像上跳 4px 300ms→`--dur-panel`）、屏幕面板（手机自下/桌面自右 280ms）、接管中（2px accent 描边呼吸 1.2s）、配对成功（.6→1.08→1 + 8 点散开 600ms，取 `--dur-slow`+`--dur-fast` 组合）、同步状态（ok 青 / 断线琥珀 + 旋转 / 恢复）。设计板中 150/200/300/600ms 与 token 档位不同处，统一取最近档位并在此记录。

补齐场景：视图/页面切换（交叉淡入 + 8px，`--dur-panel`）、弹层/底部弹层（沿用现有 Sheet 形态并接 token）、操作结果提示、空/错误/离线状态入场、列表增删（`layout`）。

### 排版 token

- 间距：`--space-1…12` = 4/8/12/16/20/24/32/40/48px（4 的倍数，设计板）。
- 字号：`--text-display` 28、`--text-title` 20、`--text-lead` 16、`--text-body` 14、`--text-meta` 12、`--text-mono` 12（设计板）；行高正文 1.5、标题 1.25。
- 目标尺寸：`--target` 44px。圆角沿用卡片 16、气泡 18、按钮 12、面板 24。
- 断点：手机 ≤ 767、平板 768–1023、桌面 1024–1279、宽屏 ≥ 1280；CSS 只允许 767/768/1023/1024/1279/1280 六个值，其他由 Vitest 拦截。
- 安全区：贴边固定元素使用 `env(safe-area-inset-*)`。

### 交互基础组件

- `components/ui/dialog.tsx`：模态基础——背景 scrim、初始焦点、Tab 循环、Esc、点击背景关闭、关闭后焦点归还、其余应用 `inert`、滚动锁定、token 动效与减少动效。`Sheet` 与 6 个自写弹窗迁移到它，不保留旧实现。
- `components/ui/state-view.tsx`：加载（ShiningText）、空、错误（附重试）、离线四态，统一排版与入场。

### 工程门禁（Vitest 静态守卫）

1. CSS token 与 `motion.ts` 数值一致。
2. 除 `tokens.css` 外，CSS 中 transition/animation 不得出现字面时长或 `cubic-bezier`。
3. TSX 中 `motion/react` 的 `duration`/`ease` 只能来自 `motion.ts`。
4. `@media` 宽度只允许六个断点值。
