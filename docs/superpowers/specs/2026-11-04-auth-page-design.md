# nekoDOT 注册与登录页

用户已提供 React 页面参考并要求据此修改，保留原有重要文案、精简次要内容。

- 桌面采用等宽左右分栏：左栏顶部品牌，底部原有产品标题与简介；背景使用参考中的双向 SVG 流线。右栏居中放置账号表单，上方放首页与语言入口。
- 网页沿用 Nunito、JetBrains Mono 和当前主题变量；原生端沿用自身黑白 Tone。标题、正文、表单和辅助文字分别建立清晰层级。装饰仅使用流线，移除原来的浮动 Bot、三项功能清单及 Web/Relay/Hermes 技术链路。
- 保留邮箱/密码登录、邮件验证码注册、旧账号补验邮箱、重置密码、错误/成功信息及中英文切换。无需第三方 OAuth、假用户评价、占位条款链接或图片。
- 宽度不足 1024px 时收起网页左栏，在表单中显示品牌；Windows/Flutter 同步分栏与线条视觉，窄屏继续可滚动。低高度与键盘弹起时表单保持可达。
- 使用确定性的动画参数；减少动效偏好下绘制静态路径，装饰不参与辅助技术导航。
- React 可复用组件位于 apps/web/src/components/ui，认证状态和请求仍由 features/auth.tsx 管理。现有 Motion 直接提供参考的路径动画，避免重复安装 framer-motion。
- 验收包括真实本地 Relay 的登录/邮件验证码注册、找回密码界面、双语、手机宽度、深色与减少动效；Flutter 进行静态分析、既有窗口/表单测试、Windows 构建与候选界面检查。模型调用不属于账号页验收。
