# W6 Bot、扩展与记忆

## 改动

- 新建/编辑 Bot：头像形象与颜色改为无间隙的 44px 命中格（`auto-fill, minmax(var(--target), 1fr)`），视觉圆点居中；手机弹层左右留白统一为 16px，390px 下一行 8 个，与设计板 04 一致，更窄屏幕换行而非缩小目标。
- 空状态：定时任务、扩展（无 Bot / 无结果）、资料库四处改用 `StateView` 紧凑空态，移除旧的 `.empty-state` 规则（不保留兼容样式）。
- 实测补充（来自真实环境走查）：
  - 手机群聊无可聚焦内容时，对话滚动区不能用键盘滚动（axe P1）。对话区改为带名称的可聚焦区域（`role="region"`、「对话记录」）。
  - 手机布局把电脑选择压到 32px 高，恢复为 44px。
- 探针：分轮等待入场动画（列表的出现可能稍后才开始），透明度为 0 的元素不计入目标尺寸；此前 35px 的命令面板选项属于尚未出现的行（44 × 0.8）。`bots`、`extensions` 纳入门禁。

## 验收

- 录制：探针 4 组 + 扩展 + 共享记忆 + 提供方 + Animated List 12 项通过；复验探针 + 私聊 2 + 群聊 + 键盘 8 项通过。四组布局中除设置页（W7）外无 P1/P2。
- 真实环境：手机深色与英文桌面深色走查；Bot、扩展、详情、资料库与记忆界面无 P1/P2。
