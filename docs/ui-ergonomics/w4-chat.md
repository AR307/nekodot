# W4 私聊与输入框

## 改动

- 最新内容不被挤出视野（F12）：原先只在消息变化时贴底；文件卡、图片、工具展开或输入框展开等晚到的布局变化会把最后一条推到可视区外。`useChatScroll` 新增 `ResizeObserver`，读者停在底部时随内容/容器尺寸变化保持贴底；翻看历史时不打扰。
- 欢迎语使用 `text-wrap: balance`，不再留下孤字（F13）。
- 输入框模型菜单各项提升到 44px。
- 设计板动效核对：消息出现 8px/220ms、流式光标 1s steps（只追加文本不逐字动画）、思考中 4px/450ms 错开 120ms、工具卡 spring 400/32 与状态切换 160ms、审批卡、Bot 接力均已接入 token（W1）。
