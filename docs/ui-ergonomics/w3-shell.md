# W3 外壳与导航

## 改动

- 点击目标：搜索入口、电脑选择、语言按钮由 36–40px 提升到 44px；电脑菜单行原本已是 48px，基线中的 38–40px 来自探针在列表弹入动画中途测量，W2 起探针先等待动画结束。
- 键盘：电脑菜单与手机「+」菜单是 `role="menu"`，新增 ↑/↓/Home/End 循环（`components/ui/menu-keys.ts`）；「+」菜单打开时焦点进入首个可用项，Esc 关闭并把焦点还给「+」。
- 弹层焦点：只读弹层（Bot 详情等）打开后聚焦面板本身，表单才聚焦首个字段，避免焦点落在操作按钮上被误触执行；面板作为阅读起点不绘制焦点框。
- 命令面板：输入框常驻焦点，去掉框内多余的焦点矩形，由搜索栏本身表达焦点。
- 会话行：新增按下态，触屏没有悬停时也能立即看到反馈（E5/E11）。
- 视图切换（聊天/Skills/插件）改用 `--dur-panel` 与 8px 上移，与设计规范的「视图切换」一致。

## 例外

- F15：电脑菜单展开时覆盖侧栏「新建 bot」按钮，axe 判为目标重叠。下拉菜单覆盖其下方控件是预期行为，菜单关闭后恢复；记录为接受的例外，该界面不纳入门禁。

## 验收

- 新增 `tests/browser/keyboard.spec.ts`：电脑菜单方向键与 Esc 归还焦点、命令面板 Tab 不外逃与关闭后回到入口、Bot 详情初始焦点在面板、手机「+」菜单焦点进出。
- 录制探针 `shell/home`、`shell/palette`、`shell/new-menu` 进入门禁；探针 4 组、Gooey Nav、Animated List、键盘共 11 项通过。
