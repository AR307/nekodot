# W2 入口：账号、启动与配对

## 改动

- 账号页
  - 密码框右侧新增 44×44「显示/隐藏密码」按钮（`aria-pressed`、`aria-controls`，中英文案），减少手机输入错误。
  - 「发送验证码」不再在邮箱为空时静默禁用：点击时就地校验，焦点回到缺失字段并显示浏览器原生提示；冷却倒计时与提交中仍禁用。
  - 提示与错误消息以 `--dur-base` 淡入并上移 4px，减少动态效果时直接出现。
- 启动页：中继不可用改用 `StateView`（错误态 + 重试），加载态同一组件。
- 配对等待卡：原先在图标位挤入「加载中…」扫光文字（被截断、与标题重复），改为设计板「同步状态」的琥珀点 + 旋转环。
- 探针：测量前等待入场动画结束（列表 pop-in 等），避免把动画中途尺寸记为目标过小；`auth`、`pair` 进入门禁，P0/P1 即失败。

## 验收

- 真实浏览器（候选 Web 4420，未登录）：邮箱为空点击「发送验证码」——无请求发出，焦点移到邮箱，提示「请填写此字段。」；显示密码后输入框变为明文、按钮 `aria-pressed=true`、名称改为「隐藏密码」、尺寸 44×44。
- 真实环境走查（真实 Relay/Node/官方 Hermes，中文桌面浅色 + 手机深色）：账号页与配对页无 P1/P2；配对页每次进入会在真实 Relay 生成一个 30 分钟后失效的配对码，未连接新电脑。
- 录制探针 4 组 + 账号相关 E2E 见提交记录与 `Summary.md`。
