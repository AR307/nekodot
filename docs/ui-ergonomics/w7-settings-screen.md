# W7 设置、系统与屏幕面板

## 改动

- 授权登录列表（F14）：根因是卡片边框引用了不存在的 `--border` token，各提供方之间没有分隔。改为 `--line` 边框卡片；名称与状态标签同行（已授权为 ok 底纹，未授权为中性）；来源说明单独一行；仅终端授权的命令改为代码块；「开始授权」「断开授权」与「原生授权说明」收拢在同一行，说明链接加下划线与外链图标，44px 高（F06）。
- 主题开关：保持 60×34 的视觉，按钮命中区改为 44px（轨道由伪元素绘制）。
- 屏幕面板：成员切换、控制条、工具栏、下拉、按键与页脚按钮由 36–40px 提升到 44px；新增「Bot 屏幕」走查步骤并纳入门禁。
- 新增 `external` 图标。

## 验收

- 录制探针：`settings`、`screen` 纳入门禁；手机两组 0 项，桌面两组仅剩已接受的 F15 与 P3。提供方旅程按新状态标签更新断言后通过。
- 真实环境：中文桌面浅色仅 P3、中文手机深色 0 项，覆盖账号、外壳、私聊、群聊、Bot、扩展、设置与屏幕面板。
- 未验：本机节点为 Windows，屏幕面板显示「当前仅支持 Linux VPS」；真实屏幕观看/接管需另一台 Linux 节点与私有屏幕验收文件（`screens-live.spec.ts`），本次未执行。
