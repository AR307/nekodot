# nekodot 0.3.0 · 正式版

本次将近期完成的 Hermes 原生能力、Webhook 例行任务及 Bot 历史 Session 切换交付到正式环境。Windows / Android 继续使用 Flutter 原生界面，不使用 WebView，不在客户端安装 Hermes。

- 官网与下载：<https://nekodot.com>
- 源码与版本：<https://github.com/AR307/nekodot/releases/tag/v0.3.0>

## 更新内容

- 聊天改用 Hermes canonical gateway WebSocket：会话、流式事件、审批、提问、steer、停止及恢复使用同一原生通路。
- 原生指令栏与能力页面：会话与历史、模型与推理、配置、工具与扩展、记忆、Goals / Loops、子 Agent、队列及原生任务结果；能力按 Hermes 和当前节点实际支持情况显示。
- Bot 历史 Session GUI：搜索、预览、新建与切换，可在原生会话中读取历史 Session。预览不会执行模型，切换不会重跑旧任务，聊天记录不会被清空。
- Webhook 例行任务：聊天创建、确认接入、保密交付、测试、暂停与密钥轮换；外部触发 Hermes 独立后台执行，结果回投私聊，不打断当前聊天。
- 保留邮箱账号、可共存模型来源、共享用户偏好、文件资料库、Skills / 插件和原生远程屏幕。

## 安装与升级

| 平台    | 安装包                                                                               | 要求                                                         |
| ------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| Windows | [nekodot-windows-x64.exe](https://nekodot.com/downloads/nekodot-windows-x64.exe)     | Windows 10 22H2 / 11 x64；安装器未做 Authenticode 发布者签名 |
| Android | [nekodot-android-arm64.apk](https://nekodot.com/downloads/nekodot-android-arm64.apk) | Android 10+ arm64；沿用原签名；versionCode 2006              |

客户端可覆盖安装。账号、节点身份、profiles、聊天历史和浏览器资料保留；服务器任务不依赖客户端保持打开。Node 继续使用现有空闲更新机制；若 App 提示需手动更新，使用它生成的安装命令，勿删除原安装目录。

正式产品 Hermes 使用已验收的 v0.22.5 和最小 Webhook listener 修复。自部署节点的安装器不会自动改写 Hermes 核心；受影响版本需要跨 profile Webhook 时，管理员参照 [原生补丁说明](../../deploy/hermes/README.md) 单独处理。
