# nekodot 0.1.0

nekodot 的首个版本：由 Hermes Agent 驱动的 AI 小队，提供 Windows 与 Android 客户端。

- 官网：<https://nekodot.com>
- 源码：<https://github.com/AR307/nekodot>
- 版本下载：<https://github.com/AR307/nekodot/releases/tag/v0.1.0>
- 许可证：[MIT](../../LICENSE)

## 安装

| 平台    | 安装包                                                                               | 要求                                                    |
| ------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| Windows | [nekodot-windows-x64.exe](https://nekodot.com/downloads/nekodot-windows-x64.exe)     | Windows 10 / 11 x64；安装器未做 Authenticode 发布者签名 |
| Android | [nekodot-android-arm64.apk](https://nekodot.com/downloads/nekodot-android-arm64.apk) | Android 10+、arm64；release APK 已签名                  |

界面随 App 安装，直接通过 HTTPS/WSS 连接产品服务，本机无需运行 Vite、SSH、Node 或 Hermes。注册后需要配对自己的服务器节点；账号不会自动取得其他人的节点权限。

## 包含的功能

- 每个 Bot 对应独立 Hermes profile；原生模型调用、工具、审批、记忆、技能与插件。
- 私聊流式回复、工具展开、允许或拒绝审批、运行中原生 steer 和停止。
- 2–6 名 Bot 群聊、`@handle` 定向与 Bot 接力；同 Bot 的私聊和群聊共享上下文。
- Bot 详情、定时任务查看、记忆编辑及整理、交付文件资料库。
- Skills / 插件目录与按 Bot 安装、配置和启用。
- Linux VPS 的原生浏览器与桌面观看、人工接管和交还。
- 中英双语、浅深色、响应式界面，以及刷新、断线和应用恢复同步。
- Android FCM 后台通用任务提醒；点击后同步到对应会话。

## 当前验收范围

此前已验证 Windows 原生宿主和 Android 模拟器中的公网聊天，以及 Android 模拟器后台 FCM 到达和点击定位。Android 真机安装、锁屏与划掉应用后的提醒、双端完整屏幕接管、Windows 干净用户安装及覆盖安装仍待补充；本次发布不将这些项目标记为通过。

屏幕能力目前面向 Linux VPS。macOS、iOS、Windows ARM、本地 Hermes 管理、商店分发与自动更新不在此版本交付范围。完整记录见 [客户端验收](../side-stage-2-acceptance.md)。

Hermes 原始仓库历史保留在 GitHub 的 `hermes-reference` 分支，产品代码位于 `main`。
