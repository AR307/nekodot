# nekodot 0.2.0 · 开发者预览版

Windows 和 Android 改用 Flutter 原生界面，屏幕由 Rust RFB 解码并绘制，不使用 WebView。官网与安装包同步更新，许可证继续采用 MIT。

- 官网与下载：<https://nekodot.com>
- 源码与版本：<https://github.com/AR307/nekodot/releases/tag/v0.2.0>

## 本次更新

- 双端重新设计：Windows 黑白实色、Android 毛玻璃；8 种 Bot 形象、16 种颜色。
- 邮箱验证码注册、已有账号补验、密码重置、可撤销登录与退出。
- Hermes 原生授权与多个自定义 API 共存，按 Bot 选择来源和模型；展示原生模型信息与压缩记录。
- Bot 真实欢迎消息、原生提问卡、输出恢复、同 run 补充指令与独立停止。
- 同账号共享用户偏好，Bot 自身设定与任务经验独立；资料库、Skills、插件及原生屏幕沿用 Hermes。
- Node 空闲时自动更新，保留上一版；已有 `1.0.0` 节点需先按 App 提示手动更新一次。

## 安装与升级

| 平台    | 安装包                                                                               | 要求                                                   |
| ------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------ |
| Windows | [nekodot-windows-x64.exe](https://nekodot.com/downloads/nekodot-windows-x64.exe)     | Windows 10 22H2 / 11 x64；未做 Authenticode 发布者签名 |
| Android | [nekodot-android-arm64.apk](https://nekodot.com/downloads/nekodot-android-arm64.apk) | Android 10+ arm64；沿用原产品签名；versionCode 2005    |

账号、节点、profiles 和历史保留。升级后重新登录，旧账号使用原密码完成邮箱补验；新注册需收取邮箱验证码。App 不在本机运行 Hermes，服务器任务不因客户端退出而停止。

## 验收范围

这是开发者预览版。已有真实 Hermes / 自定义 API / Codex 授权、共享记忆、原生屏幕及双端回放证据，分别见 [Side Phase 3 记录](../side-phase-3-progress.md) 和 [节点更新验收](../node-auto-update-acceptance.md)。本次发布的构建、官网、候选服务与线上结果见 [0.2.0 发布验收](../release-0.2.0-acceptance.md)。

Android 真机、后台/锁屏 FCM、Windows 干净用户安装与完整系统通知旅程尚未完成；模拟器、构建或官网手机尺寸截图不代表这些项目通过。官网截图使用 Flutter 演示数据，手机图为桌面上的手机尺寸渲染。
