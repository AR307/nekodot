# nekodot 0.3.1

## 新功能

- **在自己的电脑运行 Bot**：Windows 添加电脑时可选择本机，自动准备独立 Node/Hermes 运行环境、配对并启动。支持自选目录、取消重试和顶部安装进度；退出后回收所属进程。
- **本机桌面操作**：每个 Bot 单独开启操作本机的能力，默认关闭；不会把服务器的独立屏幕与本机桌面混为一谈。
- **聊天内保密交付**：Bot 可请求 API Key、密码及多行私钥。客户端加密提交，使用限于所属 Bot 的凭据引用；可选择保存以供同用途复用。
- **检查与安装更新**：Windows、Android 可检查版本并下载更新；Relay 提供运维侧更新入口。

## 修复与体验

- 修复 Windows 托盘右键菜单，登录和设置页提供明确退出入口。
- Bot 回复正常显示 Markdown，工具结果更清晰。
- 未填 handle 时按 Bot 名称生成，支持中文提及。
- 改善 Node 连接恢复、群聊启动错误显示和重复接力处理。
- 新 Bot 欢迎时提交的消息正常排队；本机安装取消立即响应，账号依赖准备阶段可见。

## 安装与验收边界

- Windows x64 安装器未做 Authenticode 发布者签名。Android arm64 沿用已有应用标识和签名，版本为 0.3.1，versionCode 2007。
- Windows 本机运行、真实文件工具、桌面操作、连续消息和重启恢复已在隔离 Node/Relay、官方 Hermes v0.22.6 与 gpt-6.1-sol 下验收；固定 Android 模拟器完成同账号访问本机节点。不是本轮 Android 真机验收。
- macOS/Linux 宿主代码已接入；macOS 无设备，暂不提供安装包。Linux 仅完成 WSL 构建和启动冒烟，未完成完整桌面验收，不列为已验收正式平台。
- 既有账号、历史和 profiles 保留；生产环境 Hermes 不随客户端发布而擅自升级。
