# nekodot 0.1.1

本次修复首次绑定服务器和 Linux 节点安装遇到的问题。

- 新配对码默认有效 30 分钟；「延长 30 分钟」保留原配对码和安装命令，过期但未使用的码也可以恢复。
- 没有绑定服务器时也能返回首页，再从首页继续绑定；修正空节点首页的重复渲染问题。
- 首次 Hermes 安装及后续项目专属运行环境使用官方 PyPI，修复部分系统镜像缺少上传时间信息导致 setuptools / psutil 依赖解析失败的问题。不修改系统 pip 配置或 Hermes 核心。
- 安装失败后可重跑同一命令，复用已经下载的程序和依赖；已绑定节点重复安装保留身份及历史。

## 安装

- [Windows x64](https://nekodot.com/downloads/nekodot-windows-x64.exe)：覆盖安装即可，未做 Authenticode 签名。
- [Android arm64](https://nekodot.com/downloads/nekodot-android-arm64.apk)：沿用原签名，versionCode 为 2。
- Linux 节点请从应用重新复制安装命令。仍在安装时可点击延长等待，不需要更换命令。

## 验证范围

真实隔离 Ubuntu 安装使用官方 Hermes 稳定版本，故意提供不可用的系统 pip 镜像仍完成依赖安装、配对和 systemd 服务启动。Edge 实测延长原码、返回无节点首页、重新进入和 390 / 768 / 1440px 布局；另回归既有私聊与群聊操作。

保留既有 profiles、历史、原安装包及验收现场。此前 Android 真机、Windows 干净用户完整安装和真实屏幕回归的未验收范围继续保留，不因本次修复视为通过。详见阶段记录及本次机器证据。
